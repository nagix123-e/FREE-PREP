# Sample Question Sets

Put bundled full-practice CSV files in this directory and register them in `manifest.json`.

Example:

```json
[
  {
    "id": "sample-full-001",
    "name": "Sample Full Practice 001",
    "description": "Bundled full-length sample practice set.",
    "filename": "sample-full-001.csv"
  }
]
```

Each sample is expected to validate as a `full_test` package.
