# Release Guide

This guide is for maintainers publishing SAT Practice Simulator through GitHub Releases.

## Before Release

Update version numbers when preparing a new release:

- `package.json`
- `src-tauri/tauri.conf.json`
- `src-tauri/Cargo.toml`
- `CHANGELOG.md`

```bash
npm install
npm run typecheck
npm run build
npm run tauri:build
```

Confirm:

- CSV import still works.
- Sample CSV imports.
- SQLite saves locally.
- Question Sets persist after restart.
- Practice Score wording is used instead of official score wording.
- No official SAT, Bluebook, or College Board branding is included.

## GitHub Desktop Publish

1. Open GitHub Desktop.
2. Add this local repository.
3. Confirm `.gitignore` excludes generated output.
4. Commit source code, docs, workflows, lock files, and Tauri config.
5. Publish repository.

## Tag Release

```bash
git status
git add .
git commit -m "Release v0.1.0"
git push origin main
git tag v0.1.0
git push origin v0.1.0
```

The release workflow runs on tags that start with `v`.
GitHub Actions creates a draft GitHub Release and uploads packaged desktop app assets.

## Expected Artifacts

Windows:

- `.msi`
- `.exe` installer when NSIS is generated by Tauri

macOS:

- `.dmg`
- `.app.tar.gz` or app archive when generated by Tauri

Linux:

- `.deb`
- `.AppImage`

Local builds are written under:

```text
src-tauri/target/release/bundle/
```

## User Download Guidance

Do not direct general users to GitHub's Download ZIP button. Download ZIP is source code for developers.
General users should download platform installers from GitHub Releases:

- Windows: `.exe` installer or `.msi`
- macOS: `.dmg`
- Linux: `.AppImage` or `.deb`

## Code Signing

Code signing and notarization are not required for this release phase.

Users may see:

- Windows SmartScreen warnings.
- macOS unidentified developer warnings.

Future releases can add signing secrets to GitHub Actions.
