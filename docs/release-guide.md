# Release Guide

This guide is for maintainers publishing SAT Practice Simulator through GitHub Releases.

## Before Release

```bash
npm install
npm run typecheck
npm run build
npm run tauri:build
```

Confirm:

- CSV import still works.
- Sample CSV imports.
- SQLite saves locally.
- Question Sets persist after restart.
- Practice Score wording is used instead of official score wording.
- No official SAT, Bluebook, or College Board branding is included.

## GitHub Desktop Publish

1. Open GitHub Desktop.
2. Add this local repository.
3. Confirm `.gitignore` excludes generated output.
4. Commit source code, docs, workflows, lock files, and Tauri config.
5. Publish repository.

## Tag Release

```bash
git tag v0.1.0
git push origin v0.1.0
```

The release workflow runs on tags that start with `v`.

## Expected Artifacts

Windows:

- `.msi`
- `.exe` if generated by Tauri

macOS:

- `.app`
- `.dmg`

Linux:

- `.deb`
- `.AppImage` when generated

## Code Signing

Code signing and notarization are not required for this release phase.

Users may see:

- Windows SmartScreen warnings.
- macOS unidentified developer warnings.

Future releases can add signing secrets to GitHub Actions.
